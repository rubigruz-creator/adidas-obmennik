ЧТО НУЖНО СДЕЛАТЬ СЕЙЧАС (ПРИОРИТЕТ: СРЕДНИЙ)
ПЕРЕРАБОТКА UI ГЛАВНОГО ЭКРАНА ФАЙЛОВ (FilesScreen)

Текущий экран функциональный, но выглядит просто — список цветных "пилюль". Нужно сделать современный, красивый UI в стиле корпоративного файлообменника.


Требования к новому UI:

Современный дизайн:

Карточки файлов с тенью и скруглёнными углами (Material 3)

Превью-иконки по типам файлов (📄 PDF, 🖼️ Изображения, 📊 Excel, 🎵 Аудио, 🎬 Видео, 📦 Архивы и т.д.)

Размер файла должен отображаться в читаемом формате (KB, MB, GB)

Дата загрузки — "2 часа назад", "вчера", "12 мая" и т.д.

Сетка (Grid View) вместо списка:

По умолчанию — сетка 2 колонки на телефоне

Возможность переключения между сеткой и списком (иконка в AppBar)

В режиме списка — более детальная информация (владелец, видимость)

Улучшенная навигация по папкам:

Хлебные крошки в виде чипсов (Material Chips) — красивые, с иконками

Кнопка "Назад" более заметная, с анимацией перехода

Пустая папка показывает красивую иллюстрацию и подсказку

FAB с дополнительными действиями:

Длинное нажатие на FAB или SpeedDial с опциями:

📁 Создать папку

📎 Загрузить файл

🖼️ Фото из галереи

📷 Фото с камеры

Pull-to-refresh для обновления содержимого свайпом вниз

Улучшенный поиск:

Поисковая строка в AppBar с анимацией раскрытия

Фильтры по типу файла (чипсы под поиском)

Сортировка: по дате, по имени, по размеру

Тёмная тема (уже есть, но улучшить):

Карточки должны хорошо выглядеть в тёмной теме

Градиенты или акцентные цвета для папок vs файлов


Сохранение состояния:

При возврате из папки — сохранять позицию скролла

Выбранный режим отображения (сетка/список) сохранять в SharedPreferences

Ограничения:

Не сломать существующий функционал — все операции с файлами/папками должны работать как раньше

Не менять API-сервисы — только UI-слой

Не менять серверную часть — всё на клиенте

Поддерживать Android 8+
