📄 ПРОМПТ ДЛЯ СЛЕДУЮЩЕГО ИИ-АГЕНТА (v5.1 – брендинг и UI/UX полировка)

Ты — профессиональный Flutter-разработчик, продолжающий проект «Кусочница» — корпоративный файлообменник.
Внимательно изучи приложенную документацию Project_map_5.0.md (полная карта проекта v5.0) и файлы исходного кода из папки lib/.
Они содержат все технические детали: сервер, БД, API и актуальную структуру Flutter-приложения.

⚡ ТЕКУЩЕЕ СОСТОЯНИЕ ПРОЕКТА (v5.0) – УЖЕ РЕАЛИЗОВАНО, НЕ ЛОМАЙ
- Полноценная иерархия папок с CRUD и навигацией
- Профиль пользователя с редактированием
- Прогресс-бары загрузки/скачивания
- Все базовые операции над файлами (загрузка/скачивание/удаление/переименование/видимость)
- Администратор управляет любыми файлами и папками
- Поиск с фильтрами по типам (FilterChips)
- Push-уведомления через WebSocket + локальные уведомления Android
- WebSocket-сервис на Node.js + Socket.IO
- Скачивание в папку Downloads с улучшенной модалью
- Material 3: карточки, сетка/список, хлебные крошки, EmptyState
- Превью-иконки FileIcon (расширены: APK, RTF, CDR, WebP и др.)
- Форматирование размера и дат, FAB с меню действий, эскизы изображений, описания файлов
- Код разделён на mixin'ы (file_operations, folder_operations, upload_operations)
- Pull-to-refresh, сортировка (по дате/имени/размеру/хозяину/видимости)
- Сохранение режима отображения, тёмная тема

✨ НОВЫЕ ФУНКЦИИ, ДОБАВЛЕННЫЕ В v5.0:

- Фильтры атрибутов в режиме поиска: «Свои», «Чужие», «Новые», «Просмотренные»
- Индикатор непросмотренных файлов (зелёный бейдж), исчезает после открытия меню
- Кнопка «Поделиться» с генерацией временной публичной ссылки (share_links, public_download)
- Исправлены хлебные крошки на всех уровнях вложенности, ошибка с BMP-миниатюрами, тип folder_id

Все серверные эндпоинты (list_files.php с полем is_new, get_share_link.php, public_download.php, mark_viewed.php) и таблицы БД (share_links, user_file_views) готовы и работают.
