### ⚠️ Известные ошибки и уроки (v5.4–v5.5)
1. **Tree-shaking вырезает приватные классы.** Все классы, используемые в другом контексте, должны быть **публичными**.
2. **PowerShell съедает символ `$`** в heredoc-строках. Лучше заменять код через VSCode.
3. **`uploadFileBytesWithProgress` не работает** — не отправляет тело запроса. Использовать `uploadFileBytes` без реального прогресса.
4. **Локальный запуск через localhost** вызывает CORS-ошибки. Тестировать на production-домене.
5. **Веб-сборка только на локальном ПК** — на сервере нет Flutter SDK. Сборка → scp на сервер.
6. **В веб-версии долгое нажатие не работает** — использовать правый клик мыши (`onSecondaryTap`) для входа в режим выбора.
