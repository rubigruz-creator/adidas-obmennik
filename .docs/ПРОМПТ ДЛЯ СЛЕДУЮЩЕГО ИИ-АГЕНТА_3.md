### ЧТО НУЖНО СДЕЛАТЬ СЕЙЧАС (ПРИОРИТЕТ: ВЫСОКИЙ)
**ДОБАВИТЬ PUSH-УВЕДОМЛЕНИЯ О НОВЫХ ФАЙЛАХ**

**Ограничения:**
- **Firebase Cloud Messaging (FCM) не использовать** — в России нестабилен, возможны блокировки.
- **Telegram Bot не использовать** — также может быть недоступен.
- Нужно использовать **исключительно WebSocket + локальные уведомления** на базе собственного сервера.

**Требования к решению:**
- Решение должно быть **универсальным**, чтобы его можно было легко подключить к другим проектам на том же сервере в будущем (отдельный сервис уведомлений).
- Уведомления должны работать даже когда приложение свёрнуто (фоновый режим) — используем `flutter_local_notifications` + `android foreground service`.
- Не должно создавать большой нагрузки на сервер (WebSocket соединения — лёгкие).
- Уведомления должны приходить **о новых загруженных файлах** (кому — всем пользователям или только админам? Для простоты сначала **только администраторам**, но с возможностью легко расширить на всех).
- При нажатии на уведомление приложение должно открываться (если закрыто) и желательно переходить на экран с новым файлом/папкой.

**Допустимая технология:**
- **WebSocket-сервер на Node.js + Socket.IO** (библиотека, которая отлично работает с Flutter и имеет встроенные механизмы переподключения).
- Для локальных уведомлений на клиенте: `flutter_local_notifications` + `permission_handler`.
- Для фоновой работы: держать WebSocket-соединение в фоновом режиме (Android позволяет это с ForegroundService).

WebSocket-сервис – отдельное приложение на Node.js, работает на порту (например, 3001), использует socket.io для связи.

PHP при загрузке файла делает HTTP-запрос к API этого сервиса (POST /notify), передавая user_id (или массив адресатов) и информацию о файле.

Сервис находит всех подключённых клиентов с этим user_id (через механизм комнат) и отправляет им событие.

Flutter подключается к сервису при запуске (после логина) и слушает события.

Шаг 3. Реализация серверной части (Node.js + Socket.IO)

Инициализация HTTP-сервера (Express) и Socket.IO.
