📄 ПРОМПТ ДЛЯ СЛЕДУЮЩЕГО ИИ-АГЕНТА (v5.2 – веб-интерфейс, документация и презентация)

Ты — профессиональный Flutter-разработчик, продолжающий проект «АДИДАС: наш обменник» (ранее «Кусочница») — корпоративный файлообменник.
Внимательно изучи приложенную документацию **Project_map_5.1.md** (полная карта проекта v5.1) и файлы исходного кода из папки `lib/`.
Они содержат все технические детали: сервер, БД, API и актуальную структуру Flutter-приложения.

⚡ ТЕКУЩЕЕ СОСТОЯНИЕ ПРОЕКТА (v5.1) – УЖЕ РЕАЛИЗОВАНО, НЕ ЛОМАЙ

### 🔷 Платформа и окружение
- Фреймворк: Flutter (Dart) с Material 3, минимальная версия SDK 3.0.0.
- Целевая платформа: **Android (APK)** – сейчас работает стабильно.
- Все зависимости актуальны: `lottie`, `flutter_svg`, `flutter_secure_storage`, `crypto`, `share_plus`, `permission_handler` и др.

### 🔷 Функциональность (базовая + v5.0 + v5.1)
- Полноценная иерархия папок с CRUD и навигацией, хлебные крошки.
- Профиль пользователя с редактированием.
- Загрузка/скачивание файлов с прогресс-барами и правильной обработкой разрешений Android 13+ (аудио, видео, изображения) и установки APK.
- Все операции над файлами: удаление, переименование, изменение видимости, перемещение между папками.
- Администратор может управлять любыми файлами и папками.
- Поиск с фильтрами по типам (FileType chips) и атрибутные фильтры: «Свои», «Чужие», «Новые», «Просмотренные».
- Сортировка: по дате, имени, размеру, владельцу, типу (общий/личный).
- Push-уведомления через WebSocket (Node.js + Socket.IO) + локальные уведомления Android (только для админов).
- Кнопка «Поделиться» генерирует временную публичную ссылку (7 дней) и открывает системное меню Share.
- Индикатор непросмотренных файлов (зелёный бейдж), исчезает после открытия меню файла.
- FAB-меню для создания папки, загрузки файла, фото из галереи/камеры.
- Сохранение режима отображения (сетка/список), тёмная тема.

### 🔷 Новые возможности v5.1 (реализованы)
- **Брендинг:** приложение называется «АДИДАС», подзаголовок «наш обменник». Логотип SVG в левом верхнем углу AppBar, анимированный логотип Lottie на Splash Screen, экране входа и Lock Screen.
- **Splash Screen:** белый радиальный фон, циклическая анимация логотипа, надписи, свайп вверх для перехода к основному экрану или входу (авторизован — сразу в файлы, нет — на логин).
- **Lock Screen:** вызывается при возврате из фона, если в профиле задан PIN-код. Пин хранится в защищённом виде (flutter_secure_storage, хеш SHA-256).
- **Улучшенный UI:** цветовая схема на базе чёрного и красного (#EF3340), обновлены ThemeData, AppBar, кнопки, скругления, шрифты.
- **Иконки приложения:** заменены на фирменные (mipmap всех плотностей + адаптивная на API 26+).
- **Права доступа:** динамический запрос разрешений для аудио, видео, установки APK. Добавлены `READ_MEDIA_*`, `REQUEST_INSTALL_PACKAGES` в манифест.

### 🔷 Серверная часть (без изменений с v5.0)
- Все эндпоинты работают:
  - `list_files.php` (с полем `is_new`)
  - `get_share_link.php`, `public_download.php`, `mark_viewed.php`
  - папочные CRUD, профиль, авторизация
- База данных MariaDB содержит таблицы: `users`, `user_sessions`, `files`, `folders`, `share_links`, `user_file_views`.
- WebSocket-сервис на порту 3001 проксируется через Nginx.

### 1. 🌐 Веб-версия приложения (отдельный сайт на БеГет - домен: https://gazonbaza.ru/ если это возможно)
- **Цель:** сделать ту же функциональность доступной через веб-браузер (настольные и планшетные устройства). И главное адаптация под браузер Safari.

Работа также по API с нашим сервером.

- **Требования:**
  - Максимальная поддержка всех текущих функций (файлы, папки, поиск, фильтры, уведомления, профиль, PIN-код?).
  - Адаптивная верстка (Responsive Layout) для широких экранов: AppBar превращается в боковую панель или верхнее меню, сетка файлов подстраивается под ширину, диалоги не растягиваются на весь экран.
  - Работа с WebSocket в браузере (Socket.IO клиент должен работать без нативных зависимостей).
  - Тёмная/светлая тема, поддержка Material 3.
  - Аутентификация через тот же API, сохранение сессии в `localStorage`/`sessionStorage` (вместо `SharedPreferences`).
  - Загрузка/скачивание файлов через браузерный диалог (HTML5 File API, `dart:html` или универсальные пакеты).
  - **Важно:** нельзя сломать существующую мобильную сборку Android. Код должен оставаться кросс-платформенным (единая кодовая база с условными платформенными ветвлениями).
- **Ожидаемый результат:** сайт, развёрнутый на том же сервере (gazonbaza.ru или поддомен), доступный по HTTPS, повторяющий все действия мобильного клиента.
- **Действия:**
  - Обновить `pubspec.yaml` (добавить web-зависимости, если нужно, например `url_launcher` для открытия файлов).
  - Настроить конфигурацию сборки под web (`flutter build web`).
  - Адаптировать UI под широкие экраны (LayoutBuilder, adaptive breakpoints).
  - Заменить платформозависимые сервисы (SharedPreferences, flutter_secure_storage, permission_handler) на web-совместимые или имитацию.
  - Реализовать “download” потоковую передачу и сохранение файлов через браузер.
  - Написать сопроводительный комментарий в коде о web-платформе.
  - Протестировать веб-версию локально и на сервере.
