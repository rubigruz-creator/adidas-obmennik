# 🏢 АДИДАС: НАШ ОБМЕННИК — Инструкция для сотрудников

## 📌 Что это такое?

**АДИДАС** — корпоративный файлообменник для быстрого и безопасного обмена документами, фото, видео и другими файлами между сотрудниками.

### Основные возможности:
- 📁 Создание папок и навигация по ним
- 📤 Загрузка файлов с телефона или компьютера
- 📥 Скачивание файлов на устройство
- 🔍 Поиск по названиям файлов
- 🔗 Отправка временных ссылок коллегам (7 дней)
- 🔐 Защита входа по логину/паролю
- 📱 PIN-код для быстрой блокировки приложения

---

## 📲 Установка мобильного приложения (Android)

### Шаг 1. Получите APK-файл
Попросите администратора или скачайте файл `app-release.apk` из корпоративного чата.

### Шаг 2. Разрешите установку из неизвестных источников
- Зайдите в **Настройки → Безопасность**
- Включите **«Неизвестные источники»** или **«Установка из внешних источников»**
- Подтвердите действие

### Шаг 3. Установите приложение
- Откройте скачанный APK-файл
- Нажмите **«Установить»**
- После установки нажмите **«Открыть»**

---

## 🚀 Первый запуск

### Экран приветствия (Splash Screen)
При запуске вы увидите анимированный логотип АДИДАС. **Проведите пальцем снизу вверх** для перехода к входу.

### Вход в аккаунт
1. Введите ваш **номер телефона** (логин)
2. Введите **пароль**
3. Нажмите **«Войти»**

### Регистрация нового пользователя
Если у вас ещё нет аккаунта:
1. Нажмите **«Зарегистрироваться»** (под формой входа)
2. Заполните поля:
   - Номер телефона
   - Пароль
   - Никнейм (отображается для коллег)
   - Полное имя
   - Должность
3. Нажмите **«Зарегистрироваться»**

---

## 🖥️ Основной экран

После входа вы попадаете на главный экран с вашими папками и файлами.

### Элементы интерфейса:
- **AppBar (верхняя панель):** логотип АДИДАС, кнопка поиска, кнопка профиля
- **Список папок и файлов:** все ваши файлы в текущей папке
- **FAB (красная кнопка с +):** главное меню — создать папку, загрузить файл, фото
- **Кнопка камеры (красная):** быстрая загрузка фото

### Режимы отображения:
- **Сетка** (значки) — для просмотра миниатюр
- **Список** — для подробной информации (имя, размер, дата)

Переключайте режим кнопкой в AppBar.

## 📁 Работа с папками

### Создание папки
1. Нажмите **красную кнопку (+)** в правом нижнем углу
2. Выберите **«Создать папку»**
3. Введите название папки
4. Нажмите **«Создать»**

### Навигация по папкам
- Нажмите на папку, чтобы открыть её
- Для возврата на уровень выше нажмите кнопку **«Назад»** (стрелка в AppBar)
- Хлебные крошки вверху показывают ваш путь

### Переименование папки
- Зажмите папку (долгое нажатие)
- Выберите **«Переименовать»**
- Введите новое название

### Удаление папки
- Зажмите папку
- Выберите **«Удалить»**
- Подтвердите действие

---

## 📤 Загрузка файлов

### Загрузить файл с устройства
1. Нажмите **красную кнопку (+)**
2. Выберите **«Загрузить файл»**
3. Выберите файл из памяти устройства
4. При желании добавьте **описание** (до 300 символов)
5. Выберите **тип файла:** «Личный» (только вы) или «Общий» (все сотрудники)
6. Дождитесь завершения загрузки

### Загрузить фото из галереи
1. Нажмите **красную кнопку (+)**
2. Выберите **«Из галереи»**
3. Выберите фото

### Сделать и загрузить фото
1. Нажмите **красную кнопку с камерой** (левый нижний угол)
2. Сделайте снимок
3. Подтвердите загрузку

---

## 📥 Скачивание файлов

1. Нажмите на файл
2. Файл автоматически скачается в папку **Downloads** на вашем устройстве
3. Для открытия скачанного файла нажмите уведомление или зайдите в папку Downloads

---

## ⚙️ Действия с файлами

Зажмите файл (долгое нажатие) для вызова меню:

| Действие | Описание |
|----------|----------|
| **Переименовать** | Изменить название файла |
| **Удалить** | Удалить файл (безвозвратно) |
| **Переместить** | Перенести файл в другую папку |
| **Сделать личным / общим** | Изменить видимость файла |
| **Поделиться** | Создать временную ссылку (7 дней) и отправить коллегам |

## 🔍 Поиск и фильтры

### Поиск файлов
1. Нажмите **значок лупы** в AppBar
2. Введите название файла
3. Результаты обновятся автоматически

### Фильтры
В строке поиска доступны фильтры:

| Фильтр | Что делает |
|--------|------------|
| **Свои** | Только ваши файлы |
| **Чужие** | Файлы коллег |
| **Новые** | Непросмотренные файлы (зелёный бейдж) |
| **Просмотренные** | Уже открытые файлы |

## 👤 Профиль пользователя

### Просмотр профиля
Нажмите **значок профиля** в AppBar (правый верхний угол).

### Редактирование профиля
- Нажмите кнопку **«Редактировать»**
- Измените: никнейм, полное имя, должность
- Нажмите **«Сохранить»**

### Выход из аккаунта
- В профиле нажмите **«Выйти»**
- Подтвердите действие

## 🔐 PIN-код блокировки

PIN-код защищает приложение от посторонних при выходе из фона.

### Установка PIN-кода
1. Зайдите в **Профиль**
2. Нажмите **«Установить PIN-код»**
3. Введите 4–6 цифр
4. Подтвердите PIN-код

### Блокировка экрана
- При сворачивании приложения оно блокируется
- При возврате введите PIN-код для разблокировки
- Неверный PIN отклоняется

### Изменение / Удаление PIN-кода
- В профиле нажмите **«Изменить PIN-код»** или **«Удалить PIN-код»**

## ❓ Часто задаваемые вопросы (FAQ)

### ❌ «Ошибка SSL» при входе
- Проверьте подключение к интернету
- Убедитесь, что на устройстве правильная дата и время
- Обратитесь к администратору

### ❌ Не открывается скачанный файл
- **Аудио/видео:** дайте разрешение на доступ к медиафайлам (Android 13+)
- **APK:** разрешите установку из неизвестных источников
- **Другие типы:** установите приложение для открытия этого формата

### ❌ Файл не загружается
- Проверьте подключение к интернету
- Убедитесь, что размер файла не превышает 300 МБ

### ❌ «Файл не найден» по ссылке
- Срок действия публичной ссылки истёк (7 дней)
- Создайте новую ссылку через меню «Поделиться»

### ❌ Белый экран при запуске
- Закройте приложение полностью
- Откройте заново
- Если не помогло — переустановите APK
