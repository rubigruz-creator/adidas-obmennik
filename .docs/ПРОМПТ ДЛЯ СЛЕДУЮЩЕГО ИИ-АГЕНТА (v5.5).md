### ⚠️ Известные ошибки и уроки (v5.4)
1. **Tree-shaking вырезает приватные классы** (`_UploadTask`, `_MultiUploadDialog`). Все классы, используемые в другом контексте, должны быть **публичными**.
2. **PowerShell съедает символ `$`** в heredoc-строках. Лучше заменять код через VSCode.
3. **`uploadFileBytesWithProgress` не работает** — не отправляет тело запроса. Использовать `uploadFileBytes` без реального прогресса.
4. **Локальный запуск через localhost** вызывает CORS-ошибки. Тестировать множественную загрузку на production-домене.

### ЗАДАЧА 1: 📦 Множественная обработка файлов (Приоритет: ВЫСОКИЙ)

**Цель:** Реализовать групповое удаление и перемещение файлов через режим выбора.

**Что нужно сделать:**

1. **Режим выбора файлов:**
   - Долгое нажатие (onLongPress) на файл/папку для входа в режим выбора
   - Появление чекбоксов на карточках/плитках файлов (в grid и list режимах)
   - Tap по карточке в режиме выбора = выбор/снятие выбора
   - Tap по карточке вне режима выбора = обычное меню файла (как сейчас)

2. **AppBar в режиме выбора:**
   - Показывает количество выбранных элементов: «Выбрано: 3»
   - Кнопка «Удалить» (иконка корзины)
   - Кнопка «Переместить» (иконка folder_move)
   - Кнопка «Отмена» (крестик/стрелка назад) для выхода из режима выбора

3. **Групповое удаление:**
   - Диалог подтверждения с количеством файлов
   - Последовательное удаление выбранных файлов через `ApiService.deleteFile`
   - SnackBar с результатом

4. **Групповое перемещение:**
   - Диалог выбора папки (использовать существующий список папок)
   - Последовательное перемещение через `ApiService.moveFile`
   - SnackBar с результатом

5. **Выход из режима выбора:**
   - По кнопке «Отмена» в AppBar
   - Автоматически после успешного удаления/перемещения

**Файлы для изменения:**
- `lib/screens/files_screen.dart` — основной экран (состояние выбора, AppBar, логика)
- `lib/widgets/file_card.dart` — добавить чекбокс в grid-режиме
- `lib/widgets/file_list_tile.dart` — добавить чекбокс в list-режиме
- `lib/screens/file_operations.dart` — можно добавить групповые операции

**Важно:**
- Сохранить обратную совместимость с текущим одиночным режимом
- Работать в обеих версиях (Android + Web)
- Код должен быть чистым, без дублирования
