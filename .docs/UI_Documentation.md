## ОБЗОР ДИЗАЙНА

Приложение «Кусочница» использует **Material 3** (Material You) — современный дизайн-язык Google с динамическими цветами, скруглёнными углами и плавными анимациями. Основной акцент — интуитивная работа с файлами и папками в корпоративной среде.

### Ключевые принципы:
- **Чистота и минимализм** — никаких лишних элементов
- **Информативность** — пользователь сразу видит тип, размер и дату файла
- **Скорость** — минимум кликов для основных действий
- **Консистентность** — единый стиль всех карточек, кнопок и диалогов
- **Доступность** — тёмная тема, читаемые шрифты, достаточные отступы

Заголовки: жирный шрифт, 16-18px

Подписи: 11-12px, серый цвет

ОСНОВНОЙ ЭКРАН (FILESSCREEN)
AppBar
Элемент	Описание
Заголовок	Имя текущей папки или «🍖 Кусочница» в корне
Кнопка поиска	Раскрывает строку поиска с анимацией
Кнопка сетка/список	Переключает режим отображения (GridView ↔ ListView)
Кнопка сортировки	Открывает BottomSheet: по дате, имени, размеру
Кнопка профиля	Переход на экран ProfileScreen
Кнопка выхода	Деавторизация, возврат на LoginScreen
Хлебные крошки (BreadcrumbChips)
Горизонтальный ряд ActionChip с иконками

Первый чипс — «Главная» (иконка дома)

Далее папки текущего пути

Клик по чипсу — мгновенный переход в папку

Фильтры по типу файла (FilterChips)
Появляются только при активном поиске

Категории: Все, Изображения, PDF, Документы, Excel, Архивы, Аудио, Видео, Текст, Код

Множественный выбор (можно выбрать несколько типов)

Режимы отображения
Сетка (GridView) — по умолчанию
2 колонки на телефоне

childAspectRatio: 0.85 (карточки чуть вытянуты по вертикали)

Отступы: 12px по краям, 10px между элементами

Карточки: FileCard для файлов, FolderCard для папок

Список (ListView)
Полноширокие карточки с горизонтальным лейаутом

Дополнительная информация: владелец, статус публичности

Карточки: FileListTile для файлов, FolderListTile для папок

FAB (FloatingActionButton)
Основная кнопка "+"

При нажатии открывает BottomSheet с опциями:

📁 Создать папку
📎 Загрузить файл
🖼️ Фото из галереи
📷 Фото с камеры
Pull-to-refresh
RefreshIndicator оборачивает содержимое

Свайп вниз обновляет список файлов и папок

Пустая папка (EmptyState)
Крупная иконка папки (полупрозрачная)

Текст: «В этой папке пусто»

Подсказка: «Нажмите «+» чтобы добавить файлы или папки»

УТИЛИТЫ ФОРМАТИРОВАНИЯ
format_file_size.dart
dart
String formatFileSize(int bytes)
0-1023 → "512 B"

1024-1048575 → "256.5 KB"

1048576-1073741823 → "15.2 MB"

Больше → "2.5 GB"

Использует NumberFormat('#.#') из intl

format_date.dart
dart
String formatRelativeDate(String dateString)
Менее минуты → "только что"

Менее часа → "5 минут назад" (склоняет минуты)

Менее 24 часов → "3 часа назад" (склоняет часы)

1 день → "вчера"

Менее 7 дней → "3 дня назад" (склоняет дни)

Больше → "12 мая" (формат d MMM на русском)

АДАПТИВНОСТЬ И ТЁМНАЯ ТЕМА
Тёмная тема
Все карточки используют Theme.of(context).colorScheme.surface

Текст автоматически становится светлым

Тени мягкие, полупрозрачные

Иконки сохраняют свои цвета (красный, синий, зелёный и т.д.)

Адаптивность
Сетка: фиксированные 2 колонки (оптимально для телефонов)

Список: полноширокие элементы (удобно для планшетов)

Хлебные крошки: горизонтальный скролл (не переносятся)

SingleChildScrollView в модалях (предотвращает переполнение)

СОХРАНЕНИЕ СОСТОЯНИЯ
Режим отображения (SharedPreferences)
Ключ: view_mode

Значения: grid (по умолчанию) или list

Сохраняется при переключении, восстанавливается при запуске

Позиция скролла (PageStorageKey)
Ключ: grid_{folderId} или list_{folderId}

При возврате из папки позиция скролла восстанавливается
