## 🎯 ЧТО НУЖНО СДЕЛАТЬ СЕЙЧАС (v5.3)

### ЗАДАЧА 1: 🔧 Исправить загрузку файлов в веб-версии
- **Проблема:** При попытке загрузить файл в веб-версии возникает ошибка в консоли браузера (JSON парсинг, файл не доходит до сервера)
- **Текущие файлы:** `lib/services/api_service.dart`, `lib/screens/upload_operations.dart`
- **Что уже сделано:** Добавлен `kIsWeb` для чтения байтов в `UploadOperations`, в `ApiService.uploadFile` используется `MultipartFile.fromBytes`
- **Что нужно:** Найти и исправить причину ошибки загрузки, проверить:
  - Правильно ли передаются байты в `MultipartFile.fromBytes`
  - Корректно ли работает `FilePicker` в веб-версии
  - Не блокирует ли Nginx/Apache загрузку из веб-версии
  - Проверить логи сервера при попытке загрузки
- **Тестирование:** `flutter run -d chrome`, загрузить файл, проверить через F12 (Network + Console)
- **Важно:** Не сломать загрузку в Android-версии

### ЗАДАЧА 2: 🎯 Добавить drag-and-drop в веб-версии
- **Цель:** Возможность перетаскивать файлы из проводника в окно браузера для быстрой загрузки
- **Реализация:**
  - Добавить обработчик `drop` на основную область контента
  - Принимать файлы через HTML5 Drag and Drop API
  - Интегрировать с существующим методом `uploadFile` в `UploadOperations`
  - Визуальная обратная связь (подсветка зоны при наведении)
  - Проверка на тип файла и размер (до 300 МБ)
- **Файлы:** создать `lib/widgets/drop_zone.dart`, обновить `lib/screens/files_screen.dart`
- **Важно:** Работает только в веб-версии (проверка `kIsWeb`), не влияет на Android
